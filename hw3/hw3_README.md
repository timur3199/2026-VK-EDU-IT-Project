**Продукт:** RepetitorGo — Uber для репетиторов

## 1. DDD — Доменные зоны

### 1.1 Поиск (Search)

**Описание:** всё что связано с поиском и фильтрацией репетиторов

**Сущности:** Tutor, Filter, Subject, Schedule  
**Глоссарий:**
- **Tutor** — репетитор, прошедший верификацию и размещённый на платформе
- **Subject** — учебный предмет (математика, английский и т.д.)
- **Filter** — набор параметров поиска (предмет, цена, формат, рейтинг)
- **Schedule** — расписание доступных слотов репетитора

---

### 1.2 Бронирование (Booking)

**Описание:** процесс выбора слота, подтверждения и отмены урока

**Сущности:** Reservation, Slot, Lesson  
**Глоссарий:**
- **Reservation** — запись на урок к конкретному репетитору на конкретное время
- **Slot** — временной промежуток в расписании репетитора (свободный или занятый)
- **Lesson** — состоявшийся или предстоящий урок

---

### 1.3 Пользователи (Identity)

**Описание:** регистрация, авторизация, профили учеников и репетиторов

**Сущности:** Student, Tutor, Role, Verification  
**Глоссарий:**
- **Student** — пользователь, который ищет и бронирует уроки
- **Role** — тип пользователя (ученик / репетитор / поддержка / админ)
- **Verification** — процесс проверки репетитора по диплому и пробному уроку

---

### 1.4 Оплата (Payments)

**Описание:** проведение платежей, комиссии платформы, выплаты репетиторам

**Сущности:** Payment, Subscription, Payout  
**Глоссарий:**
- **Payment** — транзакция за урок от ученика
- **Subscription** — премиум-подписка ученика (скидки, приоритет)
- **Payout** — выплата репетитору после состоявшегося урока

---

### 1.5 Поддержка (Support)

**Описание:** общение пользователей с командой поддержки, решение споров

**Сущности:** Ticket, Complaint, Review  
**Глоссарий:**
- **Ticket** — обращение пользователя в службу поддержки
- **Complaint** — жалоба на репетитора или ученика
- **Review** — оценка и отзыв после урока

---

## 2. BDD — Критический путь: Забронировать урок

### Критический путь приложения

```
открыл приложение
→ нашёл репетитора через поиск
→ открыл профиль репетитора
→ выбрал дату и свободный слот
→ нажал кнопку «Забронировать»
→ оплатил урок
→ получил подтверждение брони
```

### Пути бронирования (граничные случаи)

**Бронирование одного слота двумя учениками одновременно:**
- Ученик А открыл профиль репетитора и выбрал слот 12:00
- Ученик Б одновременно выбрал тот же слот
- Ученик А нажал «Забронировать» первым — бронь прошла
- Ученик Б нажал «Забронировать» — получил ошибку «слот уже занят»

**Двойное нажатие на кнопку «Забронировать»:**
- Ученик быстро нажал кнопку дважды
- Система создаёт только одну бронь (кнопка блокируется после первого нажатия)

---

### Сценарий успеха

**Дано:**  
Ученик находится на странице профиля репетитора Иванова  
И у репетитора есть 2 свободных слота на 15 мая  
И у ученика нет другой записи на это время

**Когда:**  
Ученик выбирает слот 14:00–15:00 и нажимает «Забронировать»

**Тогда:**  
Закрывается экран выбора слота и открывается экран оплаты  
После успешной оплаты открывается экран подтверждения брони (дата, время, имя репетитора)  
Слот 14:00–15:00 становится недоступным для других учеников  
Репетитор получает уведомление о новой брони

---

### Сценарий отказа

**Дано:**  
Ученик находится на странице профиля репетитора Иванова  
И у репетитора есть 2 свободных слота на 15 мая  
И у ученика **уже есть** запись к другому репетитору на 14:00–15:00

**Когда:**  
Ученик выбирает слот 14:00–15:00 и нажимает «Забронировать»

**Тогда:**  
Выплывает тостер с ошибкой: «У вас уже есть урок в это время»  
Бронь не создаётся  
Слот остаётся свободным

## 4. API-First — JSON-контракты

### GET /v1/tutors — Поиск репетиторов

**Запрос:**
```
GET /v1/tutors?subject=math&price_max=1000&format=online&rating_min=4
```

**Успешный ответ (200):**
```json
{
  "tutors": [
    {
      "id": 42,
      "name": "Иванов Иван Иванович",
      "subject": "math",
      "price_per_hour": 800,
      "rating": 4.8,
      "reviews_count": 120,
      "format": "online",
      "photo_url": "https://cdn.repetitorgo.ru/photos/42.jpg",
      "verified": true
    },
    {
      "id": 57,
      "name": "Петрова Анна Сергеевна",
      "subject": "math",
      "price_per_hour": 950,
      "rating": 4.9,
      "reviews_count": 85,
      "format": "online",
      "photo_url": "https://cdn.repetitorgo.ru/photos/57.jpg",
      "verified": true
    }
  ],
  "total": 2
}
```

**Ошибка (400):**
```json
{
  "error": "invalid_param",
  "message": "rating_min must be between 1 and 5"
}
```

---

### POST /v1/reservations — Создать бронь

**Запрос:**
```json
{
  "tutor_id": 42,
  "slot": {
    "from": "2026-05-15T14:00:00",
    "to": "2026-05-15T15:00:00"
  },
  "payment_token": "tok_abc123"
}
```

**Успешный ответ (200):**
```json
{
  "reservation_id": 1001,
  "status": "confirmed",
  "tutor": {
    "id": 42,
    "name": "Иванов Иван Иванович"
  },
  "slot": {
    "from": "2026-05-15T14:00:00",
    "to": "2026-05-15T15:00:00"
  },
  "created_at": "2026-04-16T10:32:00"
}
```

**Ошибка — слот занят (409):**
```json
{
  "error": "slot_unavailable",
  "message": "Этот слот уже занят другим учеником"
}
```

**Ошибка — конфликт в расписании ученика (409):**
```json
{
  "error": "schedule_conflict",
  "message": "У вас уже есть урок в это время"
}
```

**Ошибка — неверные поля (400):**
```json
{
  "error": "validation_error",
  "message": "Заполните все обязательные поля"
}
```
