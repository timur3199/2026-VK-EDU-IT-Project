## 1. C4 — Уровень 1: Контекст

Показывает, кто взаимодействует с системой и какие внешние сервисы используются.

```
[Ученик]    ──ищет и бронирует уроки───────────────────┐
[Репетитор] ──управляет профилем, подтверждает бронь──► [RepetitorGo] ──► [ЮКасса]   (платежи)
[Поддержка] ──отменяет брони, решает споры─────────────►              ──► [APNS/FCM]  (push)
[Админ]     ──верифицирует репетиторов──────────────────┘              ──► [SendGrid]  (email)
```

### Роли

| Актор | Действие |
|---|---|
| Ученик | Ищет репетитора, бронирует и оплачивает уроки |
| Репетитор | Создаёт профиль, управляет расписанием, подтверждает брони |
| Поддержка | Решает споры, отменяет брони |
| Админ | Верифицирует репетиторов, блокирует нарушителей |

### Внешние системы

| Сервис | Назначение |
|---|---|
| ЮКасса | Приём и обработка платежей |
| APNS / FCM | Push-уведомления (iOS / Android) |
| SendGrid | Email-рассылки и уведомления |

## 3. Стек технологий и обоснование

| Слой | Технология | Обоснование |
|---|---|---|
| **Мобильный фронтенд** | React Native | Одна кодовая база для iOS и Android — критично для MVP с ограниченным бюджетом и командой |
| **Веб-админка** | React | Тот же стек что и мобилка — переиспользование компонентов и знаний команды |
| **Бэкенд** | Python / FastAPI | Быстрая разработка, автодокументация OpenAPI с первого дня, асинхронность из коробки |
| **База данных** | PostgreSQL | Реляционная структура хорошо подходит для броней и расписаний, ACID-транзакции обеспечивают атомарность слотов |
| **Gateway** | nginx | Проверенный reverse-proxy, балансировка, SSL-терминация — дешевле облачного API Gateway на старте |
| **Платежи** | ЮКасса | Единственный разумный выбор для C2C-платформы с российскими пользователями: поддерживает СБП, карты и выплаты репетиторам |
| **Push** | APNS + FCM | Официальные сервисы Apple и Google — надёжная доставка уведомлений без посредников |
| **Email** | SendGrid | Надёжная доставляемость, аналитика открытий, готовые шаблоны |

---

## 4. Почему именно такой стек для MVP

- **React Native** позволяет запустить iOS и Android параллельно без двух отдельных команд.
- **FastAPI** даёт автоматическую документацию API с первого дня, что ускоряет работу мобильной команды.
- **PostgreSQL** — стандарт для транзакционных данных. Расписание и брони требуют строгой консистентности — NoSQL здесь не подходит.
- **nginx** перед бэкендом дешевле и проще, чем облачный API Gateway на старте.
- **ЮКасса** поддерживает СБП, карты и выплаты репетиторам как самозанятым.
